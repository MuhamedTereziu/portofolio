# Muhamed Tereziu — IT Technician & Systems Specialist Portfolio

A modern, high-performance personal portfolio website built with smooth GSAP animations, interactive 3D hero carousel cards, and full mobile optimization.

💼 **LinkedIn:** [linkedin.com/in/muhamedtereziu](https://www.linkedin.com/in/muhamedtereziu/)

---

## 🛠️ Features
- **GSAP 3D Interactive Hero Carousel:** Staggered floating cards showcasing key services and background, with parallax and mouse-tracking effects.
- **Mobile Optimized:**
  - Fully responsive horizontal touch scroll-snap carousel on mobile viewports.
  - Animated full-screen glassmorphic mobile navigation drawer.
  - Touch-friendly cards and interactive details modal.
  - Zero horizontal overflow across all device widths.
- **Service Offerings:**
  - Smart Home Automation & IoT Integration
  - Small Business IT Solutions & Office Setups
  - Software Installation, Updates & Maintenance
  - Hardware Diagnostics, Upgrades & Precision Repairs
  - Network Architecture, VLANs & VPN Security
  - Custom PC Builds & Workstations
- **Interactive Modals:** Detailed project specs, tech stack pills, and direct inquiry links for each service.
- **Contact Form & Social Integration:** Direct channels for inquiries and professional networking.
